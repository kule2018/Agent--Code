# 剧情分支设计

严格使用 brief 中的场景总数、结局数和角色数。场景总数包含结局。
从一个普通场景出发，每个普通场景给出两个选择。结局不提供选择。所有场景都能从起点到达。
最多三个布尔状态，只用已声明的状态作为选择条件和效果。至少有一次早期选择影响后续选择。
不同结局需要不同代价，不依赖世界观禁止的救援、技术或人物能力。
按 outline.schema.json 输出纯 JSON。写完逐个检查目标 ID、结局路线和当前玩家状态下的可选项。
