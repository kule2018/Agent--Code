# 剧情审核与局部修复

## 审核任务

1. 读取任务单列出的世界规则、全部场景和审核报告 Schema。
2. 将正文中的具体行动和结果逐条与世界规则对照，区分明确冲突与审美偏好。不要推测资料没有提供的设备属性，同一个根本问题只记录一次。
3. 对每个明确冲突，记录文件路径、违反的规则、逐字原文引用、原因和建议。
4. 检查建议是否也符合全部世界规则。例如禁止外部救援时，不得建议等待站外人员发现。将纯 JSON 报告写入 writeFiles 指定的报告文件。存在问题则 needs_revision，无问题则 approved 且 issues 为空。
5. 保持所有游戏文件不变，最终只汇报报告位置与问题数。

## 修复任务

1. 读取任务单列出的世界规则、场景、审核报告和场景 Schema。
2. 找到问题指向的文件，只调整被授权文件的 title 和 content，保留 id、ending 和 choices。
3. 保留该分支原有选择及其代价。例如选择休眠意味着降低消耗，同时暂停维修，不能改成与清醒分支相同的结果。
4. 删除与规则冲突的解决办法，补充符合站内资源限制的后果；只修复明确问题，不扩写新剧情。
5. 保存合法 JSON，再读取核对。最终只汇报修改文件和摘要。
