# 分支剧情大纲格式

使用下面的标题组织交付文件。每个标题下填写当前游戏的内容。

```markdown
# 剧情分支大纲

## 世界规则
列出本次分支必须遵守的限制。

## 两难处境
交代谁遇到了什么问题，为什么不能同时满足两个目标。

## 选择 A
玩家行动：
获得的收益：
付出的代价：
对应结局：结局 A

## 选择 B
玩家行动：
获得的收益：
付出的代价：
对应结局：结局 B

## 结局 A
写出选择 A 造成的结果。

## 结局 B
写出选择 B 造成的结果。

## 自检
说明两个选择的后果有何不同，以及为何符合世界规则。
```

收益和代价要具体，例如保住当下供氧但失去食物生产能力。两个结局的生存条件、资源或人物处境应当有实质差异。
